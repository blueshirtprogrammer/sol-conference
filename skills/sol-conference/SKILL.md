# Legacy Sol Conference Alias

This skill name is retained for compatibility.

Before any work, read and follow:

1. `/SYSTEM_PROMPT.md`
2. `/VISION.md`
3. `/SOL_ROOM_MASTER_SPEC.md`
4. `/skills/sol-room/SKILL.md`
5. `/CODEX_PROJECT.md`

The project has evolved from a telephony conference concept into **Sol Room**, a local-first virtual audio/video/device and agent-work fabric.

Do not make Twilio, SIP, OpenAI Realtime or another metered voice API the default architecture. Those integrations may be implemented only in the optional cloud-fallback phase.
