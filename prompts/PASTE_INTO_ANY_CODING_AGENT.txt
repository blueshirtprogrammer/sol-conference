ARCHITECTURAL INVARIANTS

- Microsoft Phone Link is the first native-cellular transport adapter; do not rebuild it first.
- Sol Fabric will own authoritative room state, media routing, policy, MCP and emergency control.
- OBS is the visual body/operator console, not the authoritative audio or call-continuity process.
- Existing ChatGPT, Claude, Gemini and other applications are ordinary media nodes.
- Media participation and tool permissions are separate.
- Every audio route is explicit and every participant receives mix-minus.
- Human speech and emergency controls have priority.
- AI-to-AI turns are bounded.
- Twilio, SIP and metered realtime model APIs are optional later fallbacks only.
- A mock, compilation result or successful button click is not hardware evidence.

CONTROL PRIORITY

1. supported application API or protocol;
2. Sol-owned typed adapter;
3. Windows UI Automation/accessibility;
4. supervised computer-use/vision fallback;
5. manual human action.

Never choose coordinate clicking when a semantic interface exists.
